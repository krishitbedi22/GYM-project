# Gym Website

## About the Project

IRONPULSE Gym & Fitness is a simple and responsive gym website created using HTML and Tailwind CSS. The website provides information about gym services, workout programs, membership plans, and contact details.

## Technologies Used

- HTML5
- Tailwind CSS (CDN)

## Features

- Responsive website design
- Simple and clean user interface
- Home section with a gym banner
- Gym services and workout programs
- Why Choose Us section
- Membership plans with sample prices
- Gym gallery section
- Testimonials section
- Contact form with basic HTML validation
- Business hours and Google Maps
- Navigation links between sections
- Hover and focus effects
